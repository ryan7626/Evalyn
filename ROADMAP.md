# Roadmap

## 0.2 alpha

- Safe differential execution for Git refs and explicitly included dirty edits.
- Pytest and Vitest adapters.
- Reproducible findings, JSON/JUnit/SARIF output, and GitHub Action integration.
- Public benchmark with 60 reviewed causal base/buggy/fixed fixtures. Two seed
  cases are implemented; the promotion gate is not met.

## After the alpha

- Go and Rust adapter contracts.
- Additional local and hosted model-provider integrations.
- Probe minimization and stronger deterministic oracle assessors.
- Resolve and persist OCI image digests for replay independent of mutable tags.
- Patch export integrations for external coding agents.

Scheduling, in-place autonomous repair, and broad browser orchestration are not
planned until the core detector meets its precision and safety gates.
